# Documentação do Projeto Bancada

Esta pasta destina-se a armazenar a documentação técnica, especificações de pinagem e diagramas do projeto **Bancada**.

## Estrutura Recomendada

- `pinout.md`: Mapeamento de pinos e sinais para Arduino Nano e Mega.
- `diagramas/`: Diagramas de conexão de hardware e esquemáticos.
